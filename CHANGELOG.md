# Changelog

Todos los cambios notables en este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [1.0.0] - 2026-05-06

### Added
- Sistema de mensajería con gestión de mensajeros, paquetes y destinos
- Tres tipos de mensajeros: Roberto (con vehículos intercambiables), Chuck Norris y Neo
- Dos destinos con diferentes restricciones: Puente de Brooklyn y La Matrix
- Tres tipos de paquetes: Paquete estándar, Paquetito y Paqueton Viajero
- Empresa de mensajería con gestión de envíos y facturación
- Sistema de vehículos (bicicleta y camión) que afectan el peso de mensajeros
- Suite completa de tests con formato BDD y cobertura del 100% (58 tests)
- Documentación técnica completa (arquitectura, desarrollo, setup, testing)
- Guías de contribución y código de conducta
- Configuración del proyecto para Wollok con estructura estándar
